# ⚓ Морской бой на SDL3

**Battleship** — это классическая игра «Морской бой» с современным графическим интерфейсом, написанная на языке C с использованием библиотеки SDL3. Сразитесь с искусственным интеллектом, настраивайте внешний вид игры и отслеживайте свою статистику!

## ✨ Особенности

*   **🎨 Полноценный графический интерфейс**: Игра использует **SDL3** для отрисовки окон, кнопок и игровых полей.
*   **🤖 Интеллектуальный противник**: ИИ обладает тактикой: запоминает попадания и атакует соседние клетки, чтобы добить подбитый корабль.[reference:0]
*   **⚙️ Гибкие настройки**: Вы можете изменить несколько игровых параметров (предположительно, уровень сложности ИИ, звук и цвет кораблей).[reference:1]
*   **🏆 Таблица рекордов**: Ваши победы над ИИ сохраняются и отображаются в отдельном экране «Результаты».
*   **🚢 Классические правила**: Расстановка кораблей (4, 3, 2, 1-палубные) и пошаговые ходы строго соответствуют оригинальной игре.[reference:2]

## 🕹️ Как играть

1.  **Начало игры**: На главном экране нажмите кнопку **«Start»**.
2.  **Ваш ход**: Курсором мыши выберите клетку на поле противника (справа) и кликните, чтобы произвести выстрел.
    *   Если вы попали в корабль, вы получаете дополнительный ход.
    *   Если промахнулись, ход переходит к компьютеру.
3.  **Ход ИИ**: Компьютер атакует ваше левое поле. Его действия отображаются на экране.
4.  **Конец игры**: Игра заканчивается, когда все корабли одной из сторон уничтожены. При вашей победе результат будет предложено сохранить в таблицу рекордов.

## 🖥️ Системные требования и сборка

### Зависимости
Для сборки игры необходимы следующие библиотеки:
*   **SDL3**: Основная библиотека для работы с окном, графикой и событиями.
*   **SDL3_ttf**: Библиотека для рендеринга текста (шрифтов).

> **Примечание**: Репозиторий уже содержит папки `SDL3-3.4.4` и `SDL3_ttf`, поэтому вам, скорее всего, не потребуется устанавливать их отдельно, если вы используете Visual Studio с правильной конфигурацией.

### Сборка в Visual Studio

1.  **Откройте решение**: Запустите Visual Studio и откройте файл `battleship.slnx`.
2.  **Выберите конфигурацию**: Убедитесь, что выбрана конфигурация сборки (например, `Debug` или `Release` и `x86` или `x64`).
3.  **Скомпилируйте проект**: В главном меню выберите `Сборка` → `Собрать решение`.
4.  **Запустите игру**: Нажмите клавишу `F5` или кнопку `Локальный отладчик Windows`.

### 🎛️ Управление
В меню: Управление осуществляется кликами левой кнопкой мыши по интерактивным кнопкам на экране.

В игре:

ЛКМ по полю противника: Произвести выстрел по выбранной клетке.

Кнопка «Menu»: В любой момент игры возвращает вас в главное меню.

Настройки: Кнопки с выбором цвета позволяют изменить внешний вид ваших кораблей.
